# WhereIsMyMoney v0.1.0

首个发布版本。Qt Quick + SQLite 的 Fluent Design（Win10 UWP 风格）个人记账程序。

## 功能

- 📅 日历记账：左侧月历点击日期记录当天账目（今天高亮、翻月、今天快捷键）
- 💸 支出/收入：名称、金额、详细内容、类别、付款方式（银行卡/微信零钱等，可自建）
- 🗂 类别与付款方式管理：设置页增删改，删除二次确认，被引用数据拒绝删除
- 📊 查询与统计：周/月/自定义区间，类型/类别/付款方式/关键词筛选，逐日柱状图与分布图
- 🎯 预算：周/月预算编制，进度三态提醒（正常/接近/超支），历史预算回看
- 🌓 深色/浅色主题切换（自动记忆）

## 安装

解压 `WhereIsMyMoney-v0.1.0-win64.zip`，运行 `WhereIsMyMoney\WhereIsMyMoney.exe`，无需安装。数据保存在 `%LOCALAPPDATA%\WhereIsMyMoney`。

系统要求：Windows 10/11 x64。
